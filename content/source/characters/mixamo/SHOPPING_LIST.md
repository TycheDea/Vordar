# Mixamo shopping list — Phase 5 inputs (VRoid base body + clips)

Mixamo has no API, so these are manual steps at https://www.mixamo.com
(free Adobe account). Total: one upload + one rigged download + 11 clip
downloads (~15 minutes of clicking). The build pipeline does the rest.

**2026-07-09 re-scope:** the four Mixamo stock characters below are dead
(fused meshes — no modular armor). The body now comes from VRoid; Mixamo is
used only as an auto-rigging service plus the clip library.

## Step 1 — auto-rig the VRoid base body

1. Upload `content/source/characters/vroid/test01_mixamo_upload.fbx`
   (generated by `scripts/asset-pipeline/glb_to_fbx.py`) via
   **Upload Character**.
2. Place the rigging markers (chin, wrists, elbows, knees, groin) when asked;
   use the default **Standard skeleton** (65 bones incl. fingers is fine —
   the build pipeline prunes to our 64-joint budget).
3. When the rigged preview animates, **Download**:
   - Format: **FBX Binary (.fbx)**, Pose: **T-Pose**
   - Save as: `content/source/characters/mixamo/human/Character.fbx`

## Step 2 — animation clips

**Animations** (with your uploaded character selected, so retargeting
previews correctly — clips are downloaded *without skin*):
- Format: **FBX Binary (.fbx)**
- Skin: **Without Skin**
- Frames per Second: **30**
- Keyframe Reduction: **none**
- **In Place: checked** whenever the option exists (walk/run/attacks)

## Folder layout (create as you download)

```
content/source/characters/mixamo/
  human/     Character.fbx  (the auto-rigged VRoid body, from Step 1)
  clips/     the 11 animation FBX files (downloaded once, without skin)
```

**Note:** animation FBXes are skeleton-only and every Mixamo auto-rig uses
the same standard skeleton, so download each clip **once** into `clips/` —
they fit any future body (race variants, chibi re-exports) with no re-download.
